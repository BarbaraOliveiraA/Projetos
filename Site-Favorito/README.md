## Sobre o Projeto
O projeto desenvolvido se trata de uma pagina web simples desenvolvida em HTML5 para praticar a estruturação de conteúdo, exibição de imagens locais organizadas em pasta, redimensionamento de elementos visuais e criação de hiperlinks externos que abrem em uma nova aba.

---

# Tecnologias Utilizadas
- HTML5
- Imagens locais organizadas em diretorio propio (/imagens)

---

# Conteudo da Pagina
O site reune uma lista de acesso rapido para os sites abaixo mais utilizados pelo desenvolvedor:
- HBO MAX
- Netflix
- Nuuvem
- Steam
- YouTube

# Como Executar o Projeto

1. Faça o download deste repositório para o seu computador.
2. Certifique-se de manter a pasta `imagens` com os arquivos correspondentes no mesmo diretório do arquivo `index.html`.
3. Dê dois cliques no arquivo `index.html` para abri-lo em qualquer navegador (Chrome, Firefox, Edge, etc.).
